# Sarthi Frontend Client

> Location-based heritage travel companion built with React 18, Vite, Tailwind CSS, and Leaflet.

---

## Features

- **Language Onboarding**: Native-script language selection (हिन्दी, தமிழ், বাংলা, English) with voice greetings.
- **Explore Map & GPS Proximity**: 150m proximity auto-detection with an on-screen GPS simulation panel.
- **Audio Story Companion**: Multi-chapter audio playback in chosen language via Gnani TTS with Web Speech fallback.
- **Live Guide AR Camera & Voice Q&A**: Real-time push-to-talk mic button powered by Gnani STT and TTS answers.
- **Day Planner & Multi-modal Transit**: Itinerary planning and transit guidance across Delhi.

---

## Getting Started

```bash
# From within frontend/
npm install
npm run dev

# Starts on http://localhost:3000
```

Calls to `/api` are automatically proxied to the backend at `http://localhost:5001`.
